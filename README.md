# INS2053 - Web Authoring and Web Management

Cấu trúc thư mục này dùng để làm bài tập, lab, và tài liệu khóa học.

Thư mục chính:
- lectures/: Tài liệu bài giảng
- labs/: Bài lab
- homework/: Bài tập từng buổi
- assignments/: Bài tập lớn
- projects/: Đồ án
- resources/: Tài nguyên (slides, links)
- templates/: Mẫu nộp bài và hướng dẫn
- assets/: Hình ảnh và tệp tĩnh
- hw-submissions/: Nơi lưu nộp (local)
- grading/: Mẫu chấm điểm

Hướng dẫn nhanh:
- Dùng mẫu trong `templates/` để tạo bài nộp.
- Mỗi buổi tạo thư mục con trong `homework/` hoặc `lectures/`.
